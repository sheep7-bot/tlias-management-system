# 🎯 排序算法可视化

一个精美的交互式排序算法可视化项目，支持 **10 种经典排序算法**的动画演示。

## ✨ 功能特性

- 🎨 **10 种排序算法**：冒泡、选择、插入、希尔、归并、快速、堆、计数、基数、Bogo
- 📊 **实时可视化**：彩色柱状图展示排序过程，不同颜色区分比较/交换/已排序/基准元素
- 📈 **统计信息**：实时显示比较次数、交换次数和运行时间
- ⏱ **速度控制**：从"极慢"到"瞬间"共 10 档速度可调
- 📏 **数组大小**：10 ~ 150 个元素自由调整
- ⌨️ **键盘快捷键**：
  - `Space` / `Enter` — 开始排序
  - `S` — 停止排序
  - `R` — 生成新数组
- 📖 **算法详情**：每种算法附带说明、复杂度分析和代码展示

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可使用，无需任何依赖或服务器。

```bash
# 在项目目录下
start index.html
# 或用浏览器直接打开
```

## 🧮 包含的算法

| 算法 | 平均时间复杂度 | 空间复杂度 | 稳定性 |
|------|---------------|-----------|--------|
| 冒泡排序 | O(n²) | O(1) | ✅ 稳定 |
| 选择排序 | O(n²) | O(1) | ❌ 不稳定 |
| 插入排序 | O(n²) | O(1) | ✅ 稳定 |
| 希尔排序 | O(n log n) ~ O(n²) | O(1) | ❌ 不稳定 |
| 归并排序 | O(n log n) | O(n) | ✅ 稳定 |
| 快速排序 | O(n log n) | O(log n) | ❌ 不稳定 |
| 堆排序 | O(n log n) | O(1) | ❌ 不稳定 |
| 计数排序 | O(n + k) | O(k) | ✅ 稳定 |
| 基数排序 | O(d·(n + k)) | O(n + k) | ✅ 稳定 |
| Bogo排序 | O((n+1)!) | O(1) | ❌ 不稳定 |

## 🛠 技术细节

- 所有排序算法使用 **ES6 Generator 函数** 实现，通过 `yield` 逐步输出比较/交换信息
- 可视化层监听 Generator 的每一步输出，实时更新柱状图
- 纯前端项目，零依赖，在浏览器中直接运行
